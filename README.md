# Planning Poker

Веб-сервис для командной оценки задач по методу Scrum (покер планирования).
Участники подключаются по коду, голосуют картами Фибоначчи, оценки вскрываются
одновременно, спорные задачи переоцениваются после обсуждения. Всё в реальном
времени через WebSocket.

Учебный проект команды **HTTP 418** (практика «Открытые Лаборатории», НГИЭУ).

## Возможности

- Создание сессии со списком задач и тегами
- Подключение участников по 6-значному коду (имя + код)
- Скрытое голосование картами `1, 2, 3, 5, 8, 13, 20, ?, пас`
- Одновременное вскрытие оценок, подсчёт мин/среднее/макс и подсказка о расхождении
- Переголосование спорных задач, фиксация итоговой оценки
- Роль модератора: управление ходом сессии, таймер раунда (в минутах)
- Перетаскивание и редактирование задач, переход к любой задаче
- Итоговая сводка с экспортом в CSV и JSON
- Персональные заметки по сессии
- Уведомления (голосование, время раунда, вход/выход участников)
- Хранение сессий 30 дней, авто-завершение брошенных сессий

## Стек

- **Сервер:** Node.js, Express, Socket.IO. Состояние в памяти + персист в JSON-файл.
- **Клиент:** React, Vite, Tailwind CSS, React Router, socket.io-client, lucide-react.
- **Хостинг:** Railway.

## Запуск локально

```bash
# установить зависимости (клиент + сервер)
npm run install:deps

# терминал 1 - сервер (порт 3001)
npm run dev:server

# терминал 2 - клиент (порт 5173)
npm run dev:client
```

Открыть http://localhost:5173. В режиме разработки Vite проксирует WebSocket на сервер.

Для прод-сборки:

```bash
npm run build      # установка зависимостей + сборка клиента
npm start          # сервер раздаёт собранный клиент и WebSocket на одном порту
```

## Структура

```
planning-poker/
├── server/
│   └── index.js            Express + Socket.IO, игровая логика, хранение
├── client/
│   ├── src/
│   │   ├── pages/          HomePage, SessionPage
│   │   ├── components/     стол голосования, карты, модалки, таймер, тосты и т.д.
│   │   └── lib/            работа с localStorage, аватары
│   └── vite.config.js
├── package.json            скрипты для запуска и деплоя
└── railway.toml            конфигурация хостинга
```

## Деплой

Репозиторий подключается к Railway. Сборку и старт описывает `railway.toml`
(`npm run build` → `npm start`). Переменная `PORT` задаётся платформой.
